# Комната 3 — свет, природа, история

[Открыть интерактивную комнату](https://antony502189-max.github.io/temka3-room-walkthrough/)

Третья отдельная версия на основе `temka2.blend`: три настенные композиции по четырём предоставленным референсам, пять рамок с изображениями документов из оригинального референса, гирлянда и верхние световые профили с тёплым светом 3000 K. Свет направлен на потолок; высота и геометрия помещения сохранены. Это визуальная концепция, а не светотехнический расчёт.

## Просмотр

WASD / стрелки — ходьба. Перетаскивание — взгляд. «Осмотр» — вращение комнаты сверху с временно скрытым потолком. Четыре ракурса ведут к общему виду и трём композициям. Справа можно выключить подсветку или изменить яркость; «Посмотреть референсы» открывает исходные изображения. На сенсорном экране доступны джойстик и поворот жестом.

## Модель и оформление

- `source/temka2.blend` — неизменённый исходник.
- `source/room3-designed.blend` — отдельная редактируемая сцена: рисунки, рамки, профили, светящиеся ленты и Blender Area Lights. Текстуры упакованы.
- `assets/room_web.glb` — сцена для браузера со встроенными текстурами.
- `assets/navigation.json` — проходы, пересчитанные по оформленной модели, включая рамки и декор.
- `assets/flax.png`, `landscape.png`, `memories.png` — плоские текстуры, воссозданные встроенным image_gen по референсам. Фотографии на фотостене являются иллюстративной интерпретацией, а не архивными оригиналами. Исходные референсы сохранены отдельно в `references/`.
- `assets/image-prompts.json` — точные запросы генерации.
- `src/lighting.js` — площадные источники света в браузере, переключение и диммер. Профили и эмиссионные ленты находятся в самой модели.

## Сборка

```sh
npm ci
npm test
npm run build
```

Node.js 24; версии Three.js и esbuild закреплены. Сборка записывает один автономный HTML в `docs/index.html`, `dist/index.html`, `artifacts/room-walkthrough.html`. Код, модель, текстуры и референсы встроены: CDN и отдельные ресурсы не требуются.

GitHub Pages: main → /docs. После изменений пересоберите и загрузите `docs/index.html`.

Для пересоздания оформления откройте исходный `source/temka2.blend` в Blender 5.2 и выполните `tools/blender/design_room.py`. Экспорт и проверка находятся в `tools/blender/`, пересчёт проходов — в `tools/navigation/` (Python, numpy, shapely, matplotlib). Ракурсы оформления сохранены в `assets/navigation.json`.

## Проверки

21 автоматический тест: управление, безопасное движение по новой области проходов, закрытая дверь, ракурсы, восстановление после потери фокуса и запасной рендерер. Браузерная проверка на Mac: WebGL2, три композиции, подсветка, диммер и четыре референса. Полные результаты — в `verification/`.

Safari и настоящий телефон отдельно не проверены. В запасном Canvas2D отображается геометрия и текстуры, но эффект площадного освещения упрощён.
